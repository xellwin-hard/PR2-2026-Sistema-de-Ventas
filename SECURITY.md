# Seguridad

Este es un proyecto académico. Si encuentras una vulnerabilidad o un problema que pueda exponer información, comunícalo directamente al responsable del equipo y evita publicar datos sensibles en Issues.

## Reglas básicas
- No subir contraseñas, tokens, claves privadas ni cadenas de conexión reales.
- Usar archivos locales de configuración y proporcionar únicamente ejemplos sin credenciales.
- No almacenar datos personales reales de clientes en pruebas o capturas.
- Revisar los cambios antes de publicarlos en el repositorio.
