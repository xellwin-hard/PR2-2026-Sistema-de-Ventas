# Acuerdos de trabajo del equipo

1. Mantener el repositorio como fuente central de los archivos del proyecto.
2. Consultar las tareas antes de comenzar cambios para evitar duplicar trabajo.
3. Asignar un responsable a cada tarea.
4. Usar commits descriptivos y relacionados con un solo cambio.
5. Revisar los cambios importantes antes de integrarlos.
6. No subir credenciales ni información privada.
7. Actualizar README y documentación cuando cambie el sistema.
8. Comunicar bloqueos y retrasos al equipo.
9. Mantener copias de respaldo de documentos importantes.
10. Registrar acuerdos y decisiones relevantes en el repositorio.

Estos acuerdos son una propuesta inicial para aprobación de todos los integrantes.
