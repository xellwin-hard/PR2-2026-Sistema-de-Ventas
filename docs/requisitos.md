# Requisitos del sistema

## Propósito
Registrar los requisitos preliminares de NexCode Sales. Deben validarse con el equipo y convertirse en criterios verificables antes de considerarlos aprobados.

## Requisitos funcionales preliminares
- RF-01: El sistema deberá permitir el inicio de sesión de usuarios autorizados.
- RF-02: El sistema deberá permitir registrar, consultar, modificar y desactivar productos.
- RF-03: El sistema deberá permitir consultar las existencias de productos.
- RF-04: El sistema deberá permitir registrar operaciones de venta.
- RF-05: El sistema deberá permitir consultar el historial de ventas.
- RF-06: El sistema deberá permitir registrar y consultar clientes.
- RF-07: El sistema deberá permitir registrar y consultar proveedores.
- RF-08: El sistema deberá contemplar la administración de promociones y preventas.
- RF-09: El sistema deberá generar reportes relacionados con ventas e inventario.

## Requisitos no funcionales preliminares
- RNF-01: La interfaz deberá ser comprensible para los usuarios previstos.
- RNF-02: Los datos deberán almacenarse de forma consistente.
- RNF-03: El sistema no deberá exponer contraseñas ni credenciales en el repositorio.
- RNF-04: Las instrucciones de instalación y ejecución deberán permitir preparar el entorno de desarrollo.

## Criterios pendientes
El equipo debe definir reglas de validación, permisos por rol, formatos de reportes, rendimiento esperado, respaldo de datos y criterios de aceptación para cada requisito.
