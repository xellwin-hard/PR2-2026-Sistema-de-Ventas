4. Completado

## Tareas iniciales

### Organización y análisis
- [ ] Revisar requisitos y alcance del sistema.
- [ ] Confirmar responsables y fechas de cada actividad.
- [ ] Mantener actualizado el README y el registro de cambios.

### Desarrollo
- [ ] Revisar el registro y consulta de productos.
- [ ] Revisar el control de inventario y validación de stock.
- [ ] Revisar el registro de ventas y el historial.
- [ ] Verificar el almacenamiento local de datos.

### Calidad
- [ ] Ejecutar las pruebas automatizadas.
- [ ] Agregar pruebas cuando se incorporen nuevas funciones.
- [ ] Corregir errores encontrados durante las pruebas.

### Documentación y entrega
- [ ] Revisar los diagramas y el manual de ejecución.
- [ ] Preparar una demostración del sistema.
- [ ] Revisar la estructura final del repositorio antes de la entrega.

## Reglas de uso
- Cada tarea debe tener una persona responsable.
- Mover las tareas de columna cuando cambie su estado.
- Describir los cambios importantes en los comentarios de la tarea.
- Marcar como completada una tarea solo después de verificarla.
