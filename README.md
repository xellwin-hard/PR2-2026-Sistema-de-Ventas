# NexCode Sales

## Sistema de Gestión de Ventas e Inventario

NexCode Sales es un sistema desarrollado para facilitar la gestión
de productos, inventario y ventas en pequeños y medianos negocios.

## Tecnologías

- C#
- .NET
- Visual Studio
- Git
- GitHub

## Objetivo

Desarrollar un sistema de gestión de ventas e inventario que permita
registrar productos, controlar existencias, realizar ventas y consultar
el historial de operaciones.

## Funcionalidades

- Inicio de sesión
- Gestión de productos
- Control de inventario
- Registro de ventas
- Clientes
- Proveedores
- Promociones
- Preventas
- Reportes
- Historial de ventas

## Estructura del proyecto

- `src/` — Código fuente
- `tests/` — Pruebas
- `docs/` — Documentación
- `resources/` — Recursos
- `CHANGELOG.md` — Historial de cambios
